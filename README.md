AINumbers.co provides a fintech intelligence suite offering deterministic, open-source tools for payments, compliance, AML/KYC, capital markets, ESG, and agentic finance. Hosted as an MCP-native platform, it delivers 598 browser-based tools, 761 live MCP tools, and OpenAPI-documented APIs, all under a CC BY 4.0 license. The platform enables run‑verify‑anchor workflows, integrates with tokenized payments, and supports standards such as ISO 20022, DORA, AML/KYC, and EU AI Act.

**Areas:** Fintech · Payments · Compliance · OpenAPI · MCP · AI

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AINumbers.co: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
